# C 语言指针完全讲解：`*`、`**`、值传递、链表与二叉树

> 这份笔记专门解决一个核心疑惑：**`Node *head`
> 明明保存的是地址，为什么传入函数后，函数修改 `head` 却不一定能改变
> `main` 中的 `head`？为什么有时用 `Node **head`，有时用
> `Node *createList(Node *head)`？**
>
> 学习目标：理解指针变量、指针指向的对象、地址运算、解引用、值传递、一级/二级指针，以及它们在链表和二叉树中的实际用法。

------------------------------------------------------------------------

## 0. 先记住最重要的结论

1.  **C 语言函数参数一律按值传递。** 指针参数也不例外。
2.  `Node *p` 是一个指针变量，里面保存某个 `Node` 对象的地址。
3.  调用 `func(p)` 时，函数得到的是 `p`
    中地址值的副本；函数参数变量和调用者的 `p` 是两个不同变量。
4.  虽然指针值被复制了，但副本仍然指向同一个节点。因此 `p->data = 100`
    可以修改原节点的数据。
5.  `p = NULL` 或 `p = malloc(...)`
    修改的是函数参数这个指针变量的副本，不会自动修改调用者的指针变量。
6.  如果函数要直接修改调用者的指针变量，就传入那个指针变量的地址：`func(&p)`，参数类型通常是
    `Node **`。
7.  如果函数把新指针作为返回值交给调用者，也可以使用一级指针参数加返回值：`p = func(p)`。
8.  **不是 `void` 就必须用 `**`。**
    是否使用二级指针，取决于函数是否需要修改调用者的指针变量，以及是否选择用返回值传回新指针。

# 1. 从普通变量开始：变量本身也有地址

先看：

``` c
int a = 10;
```

可以把内存想象成一排带地址的储物格。假设：

-   变量 `a` 放在地址 `1000`；
-   `a` 里面存储的值是 `10`。

那么：

``` c
a       // 读取 a 的值：10
&a      // 取得 a 这个变量自己的地址：假设为 1000
```

这里要区分：

-   **变量的值**：储物格里面放的东西。
-   **变量的地址**：储物格所在的位置。

`&` 是取地址运算符（address-of operator）。

``` c
int a = 10;
printf("%d\n", a);       // 10
printf("%p\n", (void *)&a); // a 的地址
```

地址具体是多少由程序运行环境决定，不要依赖示例中的假地址。

------------------------------------------------------------------------

# 2. 一级指针：`int *p`

看代码：

``` c
int a = 10;
int *p = &a;
```

逐句理解：

-   `int *p`：声明一个指针变量 `p`，它指向 `int` 类型对象。
-   `&a`：取得变量 `a` 的地址。
-   `p = &a`：把 `a` 的地址保存到 `p` 中。
-   `*p`：沿着 `p` 中保存的地址，访问那个 `int` 对象。

假设 `a` 位于地址 1000，`p` 位于地址 2000：

  表达式   含义                      示例结果
  -------- ------------------------- ----------
  `a`      `a` 的值                  `10`
  `&a`     `a` 的地址                `1000`
  `p`      `p` 中保存的地址          `1000`
  `*p`     `p` 指向对象的值          `10`
  `&p`     指针变量 `p` 自己的地址   `2000`

示意图：

``` text
指针变量 p（地址 2000）
┌────────────────────┐
│ 保存的地址：1000   │
└─────────┬──────────┘
          │ p 指向 a
          ▼
变量 a（地址 1000）
┌────────────────────┐
│ 值：10             │
└────────────────────┘
```

## 2.1 `*` 有两种常见语境

``` c
int *p;  // 声明语境：p 是指向 int 的指针
*p = 20; // 表达式语境：通过 p 访问它指向的对象，并写入 20
```

不要把声明中的 `*` 和表达式中的 `*`
混为一谈。它们都与指针类型/解引用有关，但所处语境不同。

## 2.2 为什么 `*p = 20` 能改变 `a`？

因为 `p` 保存的是 `a` 的地址。执行：

``` c
*p = 20;
```

相当于"找到 `p` 指向的那个 `int` 储物格，把里面的值改成 20"。

所以 `a` 变成 20。

``` c
int a = 10;
int *p = &a;

*p = 20;

printf("%d\n", a); // 20
```

# 3. 二级指针：`int **pp`

继续：

``` c
int a = 10;
int *p = &a;
int **pp = &p;
```

`pp` 指向的是指针变量 `p`，而不是直接指向普通整数 `a`。

``` text
pp（指向 int *）
   │
   ▼
p（保存 a 的地址）
   │
   ▼
a（值为 10）
```

  表达式   含义
  -------- ---------------------------------
  `pp`     `p` 的地址
  `*pp`    `p` 本身，即一个 `int *` 值
  `**pp`   `p` 指向的整数，也就是 `a` 的值
  `&p`     `p` 自己的地址
  `&pp`    `pp` 自己的地址

例如：

``` c
int a = 10;
int *p = &a;
int **pp = &p;

**pp = 99;

printf("%d\n", a); // 99
```

为什么？因为：

1.  `pp` 指向 `p`；
2.  `*pp` 取得 `p`；
3.  `**pp` 取得 `p` 指向的 `a`；
4.  给 `**pp` 赋值，就修改了 `a`。

**星号的层数可以帮助你理解间接访问的层数，但不要只靠数星号猜。要看每个指针实际指向什么类型的对象。**

# 4. 值传递：为什么传入指针，仍然只是传递副本？

这是整个问题的核心。

## 4.1 普通整数的值传递

``` c
#include <stdio.h>

void change(int x) {
    x = 100;
}

int main(void) {
    int a = 10;
    change(a);
    printf("%d\n", a); // 10
    return 0;
}
```

调用 `change(a)` 时，函数参数 `x` 得到 `a` 当前值的副本。`x` 和 `a`
是两个不同的变量。

``` text
main：a = 10       change：x = 10（复制来的）
                 x = 100
结束函数后：       a 仍然是 10
```

这就是值传递（pass by value）。

## 4.2 指针参数也一样是值传递

``` c
void changePointer(int *p) {
    p = NULL;
}

int main(void) {
    int a = 10;
    int *p = &a;

    changePointer(p);

    // main 中的 p 仍然指向 a
    return 0;
}
```

这里传入的确实是一个地址，但传递的是**指针变量 `p`
中所保存的地址值的副本**。

调用前：

``` text
main 中的 p ─────────► a
```

函数调用时，地址值被复制：

``` text
main 中的 p ─────────► a
函数参数 p（副本）────► a
```

执行 `p = NULL` 后：

``` text
main 中的 p ─────────► a
函数参数 p（副本）────► NULL
```

因此，调用者的 `p` 没有改变。

## 4.3 但为什么 `*p = 100` 能改变原来的数据？

``` c
void changeValue(int *p) {
    *p = 100;
}

int main(void) {
    int a = 10;
    int *p = &a;

    changeValue(p);

    printf("%d\n", a); // 100
    return 0;
}
```

虽然函数拿到的 `p` 是副本，但它和外面的 `p`
保存着同一个地址，都指向原来的 `a`。

所以：

-   `p = NULL`：改变函数参数这个指针副本。
-   `*p = 100`：通过副本中的地址，改变它指向的原对象。

这是两种完全不同的操作。

**记忆口诀：改指针副本，不等于改原指针；通过指针访问对象，可以改原对象。**

# 5. 把概念放进链表：`Node *head`

先定义节点：

``` c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

一个节点包含：

-   `data`：数据；
-   `next`：指向下一个节点的指针。

例如：

``` text
head
 │
 ▼
[10 | next] ──► [20 | next] ──► [30 | NULL]
```

这里 `head` 本身是一个指针变量，保存第一个节点的地址。

## 5.1 只修改节点数据：一级指针足够

``` c
void changeData(Node *head) {
    head->data = 100;
}
```

调用：

``` c
changeData(head);
```

为什么能修改原节点？

`head` 的副本仍然指向原来的第一个节点。`head->data` 访问的是原节点内部的
`data`，所以能修改它。

## 5.2 修改节点的 `next`：通常也只需要一级指针

``` c
void skipSecondNode(Node *head) {
    if (head != NULL && head->next != NULL) {
        head->next = head->next->next;
    }
}
```

这里修改的是**第一个节点内部的 `next` 成员**，不是函数参数 `head`
这个指针变量本身。

因此，一级指针就够了。

这点很容易混淆：

-   `head = something`：修改函数参数 `head` 自己；
-   `head->next = something`：修改 `head` 指向的节点里面的 `next` 成员。

两者修改的对象不同。

# 6. 为什么创建链表时，有时需要 `Node **head`？

假设：

``` c
Node *head = NULL;
```

希望函数创建第一个节点，并让 `main` 中的 `head` 指向新节点。

## 6.1 错误/不符合预期的写法：`void createList(Node *head)`

``` c
void createList(Node *head) {
    head = malloc(sizeof(Node));
}
```

调用：

``` c
int main(void) {
    Node *head = NULL;
    createList(head);
    return 0;
}
```

问题：

1.  `head` 是 `NULL`；
2.  调用时，`NULL` 这个指针值被复制给函数参数；
3.  函数里的 `head` 是独立的指针副本；
4.  `malloc` 的结果只赋给函数内部的副本；
5.  函数结束后，`main` 中的 `head` 仍然是 `NULL`。

而且上面的示例没有保存 `malloc`
的地址，函数结束后会造成内存泄漏，因为调用者拿不到那块内存的地址。

## 6.2 方法一：二级指针，让函数直接修改调用者的 head

``` c
#include <stdlib.h>

void createList(Node **head) {
    *head = malloc(sizeof(Node));

    if (*head == NULL) {
        return; // 分配失败
    }

    (*head)->data = 10;
    (*head)->next = NULL;
}

int main(void) {
    Node *head = NULL;

    createList(&head);

    // 如果分配成功，head 就指向新节点
    free(head);
    return 0;
}
```

逐句拆开：

``` c
Node *head = NULL;
```

`main` 中有一个一级指针变量 `head`。

``` c
createList(&head);
```

`&head` 是**指针变量 head 自己的地址**。因为 `head` 的类型是
`Node *`，所以 `&head` 的类型是 `Node **`。

``` c
void createList(Node **head)
```

函数参数是二级指针。它保存着 `main` 中那个一级指针变量的地址。

``` c
*head = malloc(sizeof(Node));
```

`*head` 取得 `main` 中原来的 `head` 指针变量。给 `*head`
赋值，就是直接修改 `main` 中的 `head`。

关系图：

``` text
main 中的变量：
head（类型 Node *）
    │
    │ &head 传给函数
    ▼
函数参数 head（类型 Node **）
    │
    │ *head 就是 main 中的 head
    ▼
main 中的 head 被赋成 malloc 返回的新节点地址
    │
    ▼
新节点 [data | next]
```

注意：函数参数 `head` 本身仍然是一个副本。只是这个副本保存了 `main` 中
`head` 变量的地址，所以可以通过 `*head` 修改调用者的指针变量。

# 7. 为什么 `Node *createList(Node *head)` 也可以？

因为另一种设计思路是：**不让函数直接修改调用者的
head，而是把新地址返回给调用者。**

``` c
#include <stdlib.h>

Node *createList(Node *head) {
    (void)head; // 这个简单示例不需要旧 head

    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = 10;
    newNode->next = NULL;

    return newNode;
}

int main(void) {
    Node *head = NULL;

    head = createList(head);

    if (head != NULL) {
        free(head);
    }

    return 0;
}
```

这里的关键是：

``` c
return newNode;
```

函数把新节点的地址作为返回值交给调用者。

``` c
head = createList(head);
```

`main` 用返回值更新自己的 `head`。

流程：

``` text
main 中 head = NULL
       │
       ▼
调用 createList(head)
       │
       ▼
函数内部 malloc 创建节点
       │
       ▼
return 新节点地址
       │
       ▼
main 执行 head = 返回值
       │
       ▼
main 中 head 指向新节点
```

这个例子里的参数 `head`
实际上没有用途。真实项目中，如果创建函数不需要旧链表头，通常可以写得更简洁：

``` c
Node *createList(void) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = 10;
    newNode->next = NULL;

    return newNode;
}

// 调用
Node *head = createList();
```

# 8. 最重要的对照：`void` 不等于必须使用 `**`

下面四种情况要分清：

  ----------------------------------------------------------------------------------------------
  任务                             函数形式                     为什么
  -------------------------------- ---------------------------- --------------------------------
  修改节点数据                     `void change(Node *p)`       通过地址修改节点对象

  修改节点内部的 `next`            `void changeNext(Node *p)`   修改节点成员，不是参数指针本身

  修改调用者的头指针，不用返回值   `void create(Node **p)`      需要访问调用者的指针变量

  创建节点并返回新头指针           `Node *create(void)`         用返回值交给调用者
  ----------------------------------------------------------------------------------------------

因此：

**不是 `void`
导致需要二级指针，而是"函数需要改变调用者的指针变量，但又不通过返回值交付新指针"这个设计选择，导致需要二级指针。**

`void`
只表示函数不向调用者返回一个普通返回值。它不决定参数必须是什么类型。

# 9. 链表头插入：一级指针返回值和二级指针两种写法

原链表：

``` text
head ──► 10 ──► 20 ──► 30 ──► NULL
```

在头部插入 `5` 后：

``` text
head ──► 5 ──► 10 ──► 20 ──► 30 ──► NULL
```

原因是头插法必须让调用者的 `head` 改为新节点。

## 9.1 二级指针写法

``` c
void insertHead(Node **head, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        return;
    }

    newNode->data = value;
    newNode->next = *head;
    *head = newNode;
}

// 调用
insertHead(&head, 5);
```

解释：

-   `newNode->next = *head`：新节点先指向原来的第一个节点；
-   `*head = newNode`：再让调用者的 head 指向新节点。

## 9.2 返回一级指针写法

``` c
Node *insertHead(Node *head, int value) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        return head; // 这里用原 head 表示失败，仅作简单示例
    }

    newNode->data = value;
    newNode->next = head;

    return newNode;
}

// 调用
head = insertHead(head, 5);
```

这里函数没有直接修改调用者的 `head`，而是返回新的头指针，由调用者接收。

实际工程中，如果需要明确区分"插入成功"和"分配失败"，可以选择返回状态码并使用二级指针，或设计其他错误处理方式，不必局限于上面这个简化示例。

# 10. 二叉树为什么也会用 `TreeNode **root`？

二叉树节点：

``` c
typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;
```

根指针：

``` c
TreeNode *root = NULL;
```

如果创建函数要直接修改调用者的根指针：

``` c
void createTree(TreeNode **root) {
    *root = malloc(sizeof(TreeNode));
    if (*root == NULL) {
        return;
    }

    (*root)->data = 10;
    (*root)->left = NULL;
    (*root)->right = NULL;
}

// 调用
createTree(&root);
```

这和链表创建头节点完全是同一个道理：

-   链表的 `head` 保存第一个节点地址；
-   二叉树的 `root` 保存根节点地址；
-   如果函数要修改调用者的 `head` 或
    `root`，就需要拿到那个指针变量本身的地址，或者用返回值交还新指针。

遍历二叉树通常只需要一级指针：

``` c
void preorder(TreeNode *root) {
    if (root == NULL) {
        return;
    }

    printf("%d ", root->data);
    preorder(root->left);
    preorder(root->right);
}
```

因为遍历只需要读取当前节点并沿着 `left`、`right`
访问子节点，不需要改变调用者的根指针。

# 11. 常见表达式速查表

假设：

``` c
Node *head = NULL;
Node **pp = &head;
```

  表达式         意思
  -------------- ------------------------------------
  `head`         `head` 中保存的节点地址
  `&head`        `head` 这个指针变量自己的地址
  `*head`        访问 `head` 指向的整个 `Node` 对象
  `head->data`   访问头节点的 `data` 成员
  `head->next`   访问头节点的 `next` 指针成员
  `pp`           保存 `head` 地址的二级指针
  `*pp`          `head` 这个一级指针变量
  `**pp`         如果 `head` 有效，访问头节点对象

特别注意：当 `head == NULL` 时，不能解引用 `*head`，也不能访问
`head->data`。必须先检查指针是否有效。

## 11.1 `(*head)->data` 为什么要加括号？

当 `head` 是 `Node **` 时：

``` c
(*head)->data
```

意思是：

1.  `*head`：取得一个 `Node *`；
2.  `->data`：访问这个节点的 `data` 成员。

括号很重要，因为 `->` 的优先级高于一元 `*`。

# 12. 常见错误清单

## 错误一：以为传指针就能改调用者的指针

``` c
void reset(Node *head) {
    head = NULL;
}
```

这只会修改函数参数副本。

## 错误二：二级指针调用时忘记取地址

``` c
void create(Node **head) {
    /* ... */
}

Node *head = NULL;
create(head);  // 错误：类型不匹配
```

应该：

``` c
create(&head);
```

## 错误三：把 `*head` 和 `head` 搞反

当 `head` 类型为 `Node **`：

-   `head` 类型是 `Node **`；
-   `*head` 类型是 `Node *`；
-   `(*head)->data` 才是节点的数据成员。

## 错误四：忘记检查 `malloc`

``` c
Node *p = malloc(sizeof(Node));
if (p == NULL) {
    // 分配失败，不能继续访问 p->data
    return;
}
```

## 错误五：解引用空指针

``` c
Node *head = NULL;
head->data = 10; // 错误：空指针不能解引用
```

应先分配成功并检查：

``` c
Node *head = malloc(sizeof(Node));
if (head != NULL) {
    head->data = 10;
}
```

# 13. 用一个判断流程决定要不要 `**`

每次写函数前，先问自己：

**问题 1：我只需要修改节点里面的数据或成员吗？**

-   是：通常 `Node *p` 就够了。
-   例如：`p->data = 100`、`p->next = anotherNode`。

**问题 2：我需要把调用者的指针变量本身改成另一个地址吗？**

-   是：继续看问题 3。

**问题 3：我是否打算通过函数返回值把新指针交给调用者？**

-   是：可以返回 `Node *`，调用者写 `head = function(...)`。
-   否：通常传入 `Node **`，调用者写 `function(&head)`，函数内部写
    `*head = newNode`。

# 14. 练习题：检验是否真正理解

先自己判断，再看答案。

## 题目 1

``` c
void test(Node *p) {
    p->data = 100;
    p = NULL;
}
```

调用：

``` c
Node *head = malloc(sizeof(Node));
head->data = 10;

test(head);
```

执行后：

-   `head` 是否为 `NULL`？
-   `head->data` 是多少？

**答案：** `head` 不是 `NULL`，`head->data` 是 `100`。

原因：

-   `p->data = 100` 修改原节点；
-   `p = NULL` 只修改函数内部的指针副本。

## 题目 2

``` c
void test(Node **p) {
    *p = NULL;
}
```

调用：

``` c
Node *head = malloc(sizeof(Node));
test(&head);
```

执行后，`head` 是什么？

**答案：** `head == NULL`。

原因：`p` 保存的是 `head` 变量的地址，`*p` 就是调用者的 `head` 变量。给
`*p` 赋值会修改调用者的指针。

注意：这个例子没有 `free`
原节点，会造成内存泄漏。真实代码应先妥善释放或保存原节点地址。

## 题目 3

函数：

``` c
Node *create(Node *p) {
    Node *newNode = malloc(sizeof(Node));
    if (newNode == NULL) {
        return NULL;
    }

    newNode->data = 10;
    newNode->next = NULL;
    return newNode;
}
```

哪种调用可以让 `main` 中的 `head` 得到新节点地址？

A.  

``` c
create(head);
```

B.  

``` c
head = create(head);
```

C.  

``` c
create(&head);
```

**答案：B。** 函数返回新地址，调用者必须接收返回值。

# 15. 最终总结：把这四句话真正记住

1.  **`Node *p` 是指针变量，里面存储节点地址。**
2.  **C 语言始终值传递：传 `p` 给函数，传的是地址值的副本。**
3.  **`p->data` 修改的是节点对象；`p = ...` 修改的是函数参数指针副本。**
4.  **要修改调用者的指针变量，可以传 `&p`（形成
    `Node **`），也可以返回新指针让调用者接收。**

最后再看三种形式：

``` c
// 只修改节点内容
void changeData(Node *p);

// 直接修改调用者的指针变量
void changePointer(Node **p);

// 返回新指针，由调用者接收
Node *createNode(void);
```

**真正的判断标准不是函数是不是
`void`，也不是链表还是二叉树，而是：你要修改的是"节点对象"，还是"调用者手里的指针变量"？**
