# C 语言指针用法全解：下标、实参、形参、一步一个元素和一步整段数组

>

> 以及函数形参写成 `int`、`int *`、`int[]`、`int[5]`、`int (*)[5]`、`char *`、`char[]`、`struct`、`struct *` 时，实参该传什么，函数里 `+1` 跨过的是一个元素还是整段数组。

## 0. 先记住三条

1. **先看类型，再看 `+1`。** 指针加 1，跨过的字节数 = `sizeof(它指向的类型)`。指向 `int` 就跨过 1 个 `int`；指向“有 5 个 `int` 的数组”就跨过 5 个 `int`。
2. **C 的函数参数一律按值传递。** 传地址时，复制的是地址这个数。函数里 `p = ...` 改的是形参自己；`*p = ...` 或 `p[i] = ...` 改的是这块地址上的原数据。
3. **数组名在绝大多数表达式里会变成“指向首元素的指针”。** 只有 `sizeof 数组名` 和 `&数组名` 还把它当成整段数组。一进函数，`int a[]` 和 `int a[5]` 都变成 `int *`，`sizeof` 不再是整段长度。

下面所有“假设地址”只用来看偏移。真实地址每次运行都不同，用 `%p` 打印，参数写成 `(void *)地址`。

## 1. 固定一组内存，后面所有式子都指它

```c
int nums[5] = {10, 20, 30, 40, 50};
```

假设 `int` 占 4 字节，`nums` 从地址 `0x1000` 开始。五个元素紧紧排成一行：

```text
下标        [0]      [1]      [2]      [3]      [4]
值           10       20       30       40       50
地址      0x1000   0x1004   0x1008   0x100C   0x1010
                                          数组结束后: 0x1014
```

整段数组占 `5 * 4 = 20` 字节，从 `0x1000` 到 `0x1014` 之前。

再放一个字符串和一个结构体，后面字符、结构体两节用同一套算法：

```c
char word[] = "abc";   /* 实际是 'a' 'b' 'c' '\0'，共 4 字节 */

struct Student {
    int id;
    char name[8];
    char *nick;
};
```

`char` 占 1 字节。所以字符指针 `+1` 跨 1 字节；`int` 指针 `+1` 跨 4 字节；结构体指针 `+1` 跨 `sizeof(struct Student)` 个字节（含对齐补上的空隙），也就是**一个学生**。

## 2. 每个符号在表达式里做什么

| 写法 | 它做的事 |
| --- | --- |
| `nums` | 在普通表达式里变成 `&nums[0]`，类型是 `int *` |
| `&nums` | 取整段数组的地址，类型是 `int (*)[5]`。地址数值仍是 `0x1000` |
| `*p` | 顺着 `p` 里的地址，读出那个对象 |
| `p[i]` | `*(p + i)`，第 i 个元素的值 |
| `&p[i]` | `p + i`，第 i 个元素的地址 |
| `p + i` | 地址向前跨过 i 个“p 指向的对象”，p 自己不变 |
| `p += i`、`p++` | 同一段跨步，并且 p 自己改指向 |
| `对象.成员` | 对象是结构体变量时用 |
| `指针->成员` | 指针指向结构体时用，等于 `(*指针).成员` |

两种 `*` 不要混：

```c
int *p;    /* 声明：p 是指向 int 的指针 */
*p = 20;   /* 表达式：写下 p 指向的那个 int */
```

`p + 1` 只算出一个新地址，`p` 仍指向原来的地方。`p += 1` 和 `p++` 才会把 `p` 自己挪走。数组名 `nums` 可以写 `nums + 1`，不能写 `nums++` 或 `nums += 1`，因为数组名不是一个能改指向的变量。`&nums++`、`&nums[0]++` 同样不行：`&` 得到的是地址值，不是一个可以 `++` 的指针变量。

## 3. 下标的全部等价写法：`nums[i]`、`i[nums]`、`&nums[i]`、`&i[nums]`

下标的定义是：

```text
a[b]  ==  *(a + b)  ==  *(b + a)  ==  b[a]
```

所以下标写在左边还是右边，只要一边是地址、一边是整数，结果相同。正式代码写成 `nums[i]`。

设 `int i = 2;`，数组仍是上面的 `nums`。

| 表达式 | 等于 | 类型 | 结果 |
| --- | --- | --- | --- |
| `nums[2]` | `*(nums + 2)` | `int` | `30` |
| `nums[i]` | `*(nums + i)` | `int` | `30` |
| `i[nums]` | `*(i + nums)` | `int` | `30` |
| `2[nums]` | `*(2 + nums)` | `int` | `30` |
| `&nums[2]` | `nums + 2` | `int *` | `0x1008` |
| `&nums[i]` | `nums + i` | `int *` | `0x1008` |
| `&i[nums]` | `&nums[i]` | `int *` | `0x1008` |
| `*(&nums[i])` | `nums[i]` | `int` | `30` |
| `&(*nums)` | `&nums[0]` | `int *` | `0x1000` |
| `*nums` | `nums[0]` | `int` | `10` |
| `*(nums + 2)` | `nums[2]` | `int` | `30` |

如果 `i` 本身是指针，而 `num` 是下标，写法换成：

```c
int *i = nums;   /* i 指向 nums[0]，地址 0x1000 */
int num = 2;

i[num];     /* 30，等于 *(i + num)，等于 nums[2] */
&i[num];    /* 0x1008，等于 i + num，等于 &nums[2] */
*i;         /* 10，当前指向的那个元素 */
i + 1;      /* 0x1004，算出下一个元素的地址，i 仍是 0x1000 */
i++;        /* i 自己变成 0x1004，之后 *i 是 20 */
&i;         /* i 这个指针变量自己的地址，类型是 int **，不是数组里的地址 */
```

四件不同的事：

| 你写的 | 得到的是 |
| --- | --- |
| `i[num]` 或 `nums[i]` | 元素的**值** |
| `&i[num]` 或 `&nums[i]` | 那个元素的**地址**，类型 `int *`。再 `+1` 仍是下一个元素 |
| `&i`（`i` 是指针变量） | 指针变量自己的地址，类型 `int **` |
| `&nums` | 整段数组的地址，类型 `int (*)[5]`。再 `+1` 跨过 5 个 `int` |

`&` 的优先级低于 `[]`，所以 `&nums[i]` 就是 `&(nums[i])`，是“这个元素的地址”。它不是 `(&nums)[i]`。

## 4. 一步一个元素，还是一步等于整个数组

地址数值可以一样，类型不一样，`+1` 的步长就不一样。

```c
int nums[5] = {10, 20, 30, 40, 50};

int *p = nums;            /* 或 int *p = &nums[0]; */
int (*whole)[5] = &nums;  /* 圆括号必须有 */
```

| 表达式 | 类型 | 地址数值 | `+1` 之后 | 这一步跨过 |
| --- | --- | --- | --- | --- |
| `nums` | 表达式里是 `int *` | `0x1000` | `0x1004` | 1 个 `int`，4 字节 |
| `&nums[0]` | `int *` | `0x1000` | `0x1004` | 1 个 `int` |
| `p` | `int *` | `0x1000` | `0x1004` | 1 个 `int` |
| `&nums` | `int (*)[5]` | `0x1000` | `0x1014` | 5 个 `int`，20 字节，整段 |
| `whole` | `int (*)[5]` | `0x1000` | `0x1014` | 整段数组 |

图：

```text
p 或 nums：  0x1000 -> 0x1004 -> 0x1008 -> 0x100C -> 0x1010
             [10]     [20]      [30]      [40]      [50]
             一步一个元素

whole 或 &nums：
             0x1000 ----------------------------> 0x1014
             [10, 20, 30, 40, 50]  当成一个整体跨过去
```

从 `whole` 里拿出元素，先解开这一层“整段数组”：

```c
(*whole)[0];     /* 10 */
(*whole)[2];     /* 30 */
whole[0][2];     /* 30。whole[0] 就是它指向的那一整段 */
*whole[0];       /* 10，等于 (*whole)[0] */
```

`*whole[i]` 和 `(*whole)[i]` 不是同一种括号位置。`[]` 比一元 `*` 优先，所以 `*whole[i]` 是 `*(whole[i])`。只有一个数组时用 `(*whole)[i]` 或 `whole[0][i]`。

### 4.1 `sizeof` 跟着“它还是不是数组”变

仍在定义 `nums` 的那个函数里：

| 表达式 | 得到什么 | 常见 64 位结果 |
| --- | --- | --- |
| `sizeof nums` | 整段数组 | `20` |
| `sizeof(nums[0])` | 一个元素 | `4` |
| `sizeof nums / sizeof nums[0]` | 元素个数 | `5` |
| `sizeof &nums` | 指针自己 | `8` |
| `sizeof *(&nums)` | 解开数组指针，又变回整段数组 | `20` |
| `sizeof(nums + 0)` | `nums + 0` 已经是 `int *` | `8` |
| `sizeof p` | 指针变量 | `8` |
| `sizeof *whole` | `*whole` 的类型是 `int[5]` | `20` |

元素个数只能在 `nums` 还是数组的地方算：

```c
int len = (int)(sizeof nums / sizeof nums[0]);  /* 5 */
```

`nums` 一旦作为实参传进函数，形参只是指针，`sizeof` 形参得到的是 8，除出来不是 5。长度在定义数组的函数里算好，单独传进去。

### 4.2 同类型指针相减，得到的是隔着几个元素

```c
int *a = &nums[0];
int *b = &nums[3];

b - a;    /* 3，不是 12。编译器已经按 sizeof(int) 除过 */
a - b;    /* -3 */
```

`b - a` 的单位是元素个数。要看字节差，再乘 `sizeof(int)`。两个互不相关的对象不要做减法，也不要用 `<`、`>` 比它们的地址。`==` 和 `!=` 可以用来问“是不是同一个地址”。

## 5. 字符数组和字符指针

```c
char word[] = "abc";          /* 数组里有一份副本：'a' 'b' 'c' '\0' */
char *text = "abc";           /* 指向字面量，不要改字面量里的字符 */
const char *safe = "abc";
```

`word` 占 4 字节。假设从 `0x2000` 开始：

```text
[0] 'a'   0x2000
[1] 'b'   0x2001
[2] 'c'   0x2002
[3] '\0'  0x2003
结束后    0x2004
```

| 表达式 | 类型 | `+1` 跨过 |
| --- | --- | --- |
| `word`、`&word[0]`、`char *p = word` | `char *` | 1 个 `char`，1 字节。`word + 1` 是 `'b'` 的地址 |
| `&word`、`char (*whole)[4] = &word` | `char (*)[4]` | 4 个 `char`，整段，落到 `0x2004` |
| `text` | `char *` | 1 个字符。`text = word` 可以改指向 |
| `word[i]`、`i[word]`、`*(word + i)` | `char` | 那个字符的值 |
| `&word[i]`、`&i[word]`、`word + i` | `char *` | 那个字符的地址 |

`%s` 从给定地址一直打印，直到遇见 `'\0'`。`word` 有结束符，可以 `printf("%s", word)`。

```c
char bad[] = {'a', 'b', 'c'};   /* 没有 '\0'，不能当 %s 用 */
```

长度的两套算法：

| 算法 | `word[] = "abc"` 的结果 | 含义 |
| --- | --- | --- |
| `sizeof word` | `4` | 数组占的字节，含 `'\0'`。只在 `word` 还是数组时成立 |
| `sizeof word / sizeof word[0]` | `4` | 格子个数，含结束符 |
| `strlen(word)` | `3` | 结束符前面的字符个数。需要 `<string.h>` |

`char` 一步就是 1 字节，所以“一个一个走”在字符数组上看起来和“一个字节一个字节走”重合。换成 `int nums`，一步仍是一个元素，但字节是 4。步长看的是元素类型，不是永远 1 字节。

字符数组和字符指针能做的事不同：

| | `char word[] = "abc"` | `char *text = "abc"` |
| --- | --- | --- |
| 改某个字符 | `word[0] = 'A'` 可以，改的是副本 | 改字面量是未定义行为，不要写 `text[0] = 'A'` |
| 改指向 | `word = 别处` 不行 | `text = word` 或 `text = "hi"` 可以 |
| `sizeof` | 整段数组的字节数 | 指针自己，通常 8 |

## 6. 结构体、结构体指针、结构体数组

```c
struct Student {
    int id;
    char name[8];
    char *nick;
};

struct Student stu = {1, "ann", "an"};
struct Student *sp = &stu;
struct Student cls[3] = {
    {1, "ann", "an"},
    {2, "bob", "bo"},
    {3, "cy",  "c"}
};
```

访问成员的三种写法，在 `sp == &stu` 时是同一个成员：

```c
stu.id = 1;
(*sp).id = 1;
sp->id = 1;
```

`->` 的优先级高于一元 `*`。二级指针时写成 `(*pp)->id`，括号不能省。

### 6.1 结构体里的字符数组和字符指针

`name` 是数组，`nick` 是指针。规则和第 5 节一样，只是它们住在结构体里面。

| 表达式 | 类型 | `+1` 跨过 |
| --- | --- | --- |
| `stu.name`、`&stu.name[0]`、`sp->name` | 表达式里是 `char *` | 1 个字符 |
| `&stu.name`、`&sp->name` | `char (*)[8]` | 8 个字符，整段 `name` |
| `stu.name[i]`、`sp->name[i]` | `char` | 第 i 个字符的值 |
| `&stu.name[i]` | `char *` | 第 i 个字符的地址 |
| `stu.nick`、`sp->nick` | `char *` | 1 个字符。这是 `nick` 里保存的那个地址 |
| `&stu.nick` | `char **` | 跨过一个指针。用来修改 `stu.nick` 自己指向谁 |

`name` 是数组，定义之后不能写 `stu.name = "bob"`。初始化时写在花括号里可以；之后用 `strcpy(stu.name, "bob")`（要保证 `name` 装得下，含 `'\0'`）。

`nick` 是指针，可以写 `stu.nick = "bob"`，这是改指向。不要改字符串字面量里的字符。

### 6.2 一个学生，还是一整班

```c
struct Student *one = cls;                 /* 或 &cls[0] */
struct Student (*all)[3] = &cls;
```

| 表达式 | `+1` 跨过 |
| --- | --- |
| `one`、`cls`、`&cls[0]` | 1 个 `struct Student` |
| `&cls`、`all` | 3 个 `struct Student`，整段数组 |
| `&cls[i]` | 从第 i 个学生开始，再 `+1` 仍是下一个学生 |
| `cls[i]` | 第 i 个学生这个对象，类型是 `struct Student` |
| `&cls[i].id` | 一个 `int` 的地址，再 `+1` 跨的是 `int`，会走进这个结构体的后面几个字节。要下一个学生，用 `&cls[i] + 1` 或 `cls + i + 1` |

```c
cls[1].id;          /* 2 */
(cls + 1)->id;      /* 2，cls + 1 跨过一个学生 */
(&cls[0] + 1)->id;  /* 2 */
(*all)[1].id;       /* 2 */
all[0][1].id;       /* 2 */
```

## 7. 函数：形参怎么写，实参怎么传

形参是定义函数时括号里的变量，是这个函数的局部变量。实参是调用时传进去的那个值。调用时复制实参的值给形参。

下面每一小节都按同一套看：

- 形参的类型
- 实参该写什么
- 函数里哪种赋值能影响调用者
- 形参 `+1` 跨过多少
- 函数里 `sizeof` 得到什么

### 7.1 传元素的值：形参 `int`

```c
void set_value(int x) {
    x = 100;                 /* 只改形参这份副本 */
}

set_value(nums[2]);          /* 实参是 30 这个数 */
set_value(2[nums]);          /* 同一个数 */
set_value(*nums);            /* 实参是 10 */
```

调用结束，`nums[2]` 仍是 30。这里没有指针，也不存在“走一个元素”。

### 7.2 传一个元素的地址：形参 `int *`，实参 `&nums[i]`

```c
void set_element(int *p) {
    *p = 100;                /* 改这个地址上的原元素 */
    p = p + 1;               /* 只挪形参，调用者的指针不动 */
}

set_element(&nums[2]);       /* 实参类型 int *，指向 30 */
set_element(&2[nums]);       /* 同一个地址 */
set_element(nums + 2);       /* 同一个地址 */
```

返回后 `nums[2]` 是 100。`main` 里的 `nums` 不会因为函数里的 `p = p + 1` 而改变，因为 `nums` 根本不是这个形参。

如果调用者自己有指针变量，传的是指针里的地址值：

```c
int *cursor = &nums[2];
set_element(cursor);         /* 复制 cursor 里的地址。*p 能改 nums[2] */
                             /* 函数里 p = NULL 改不了 cursor */
```

要让函数改 `cursor` 自己，实参必须是 `&cursor`，形参是 `int **`，函数里写 `*p = ...`。这和 [指针.md](指针.md) 里 `Node **head` 是同一件事。

### 7.3 传数组名：形参写成 `int *`、`int[]`、`int[5]`，三者相同

这是“一个一个走”的函数写法。

```c
void walk_each(int *p, int len) {
    /* sizeof p 是指针大小，通常 8，不是 20 */
    for (int i = 0; i < len; i++) {
        p[i] = p[i] + 1;     /* 改原数组。p[i] 就是 *(p + i) */
    }
    p + 1;                   /* 跨过 1 个 int */
}

void walk_each_b(int p[], int len) { /* 和 int *p 完全相同 */ }
void walk_each_c(int p[5], int len) { /* 方括号里的 5 被忽略，仍是 int * */ }
```

实参这几种都是“指向某个 `int` 的地址”：

```c
int len = (int)(sizeof nums / sizeof nums[0]);

walk_each(nums, len);        /* 从 [0] 开始，一步一个 int */
walk_each(&nums[0], len);
walk_each(&nums[2], len - 2);/* 从 [2] 开始，函数眼里的“第 0 个”是原来的 30 */
walk_each(nums + 2, 3);
```

函数收到的是首元素地址的副本。所以：

- `p[i] = ...`、`*(p + i) = ...` 改原数组
- `p++` 只挪函数自己的副本，`main` 里的 `nums` 不动
- 方括号里写 `5` 或 `100` 都不会在函数里开辟新数组，也不会让 `p + 1` 跨过 5 个元素
- 长度必须另传。函数里再 `sizeof p / sizeof p[0]` 得到的不是 5

### 7.4 传整段数组的地址：形参 `int (*)[5]`，实参 `&nums`

这是“一步等于整个数组长度”的函数写法。

```c
void walk_whole(int (*block)[5]) {
    (*block)[2] = 100;       /* 改原数组的 nums[2] */
    block + 1;               /* 跨过 5 个 int，20 字节 */
    /* sizeof *block == sizeof nums == 20 */
    /* 元素个数可以写成 sizeof *block / sizeof(*block)[0] */
}

walk_whole(&nums);           /* 实参类型必须是 int (*)[5] */
```

`walk_whole(nums)` 类型不对：`nums` 在实参位置变成 `int *`，不是 `int (*)[5]`。

若连续放了两段长度都是 5 的数组，`block + 1` 才落在第二段的开头。只有一段时，`block + 1` 已经到这段数组的后面，不能再解引用。

`int block[][5]` 作为形参，第一维会被调整掉，实际就是 `int (*block)[5]`。列数 5 留在类型里，`+1` 才知道要跨 5 个 `int`。

### 7.5 两种传法对照

```c
int nums[5] = {10, 20, 30, 40, 50};

void by_element(int *p, int n);     /* 实参：nums 或 &nums[0] */
void by_block(int (*p)[5]);         /* 实参：&nums */
```

| | `by_element` | `by_block` |
| --- | --- | --- |
| 形参 | `int *`、`int[]`、`int[5]` 都一样 | `int (*p)[5]` |
| 实参 | `nums`、`&nums[0]`、`&nums[i]`、`nums + i` | `&nums` |
| `+1` | 1 个 `int` | 5 个 `int`，整段 |
| 改元素 | `p[i] = ...` | `(*p)[i] = ...` 或 `p[0][i] = ...` |
| 函数里能算出长度吗 | 不能，`sizeof p` 是指针 | 能，`sizeof *p / sizeof(*p)[0]` |
| 调用者的数组名会变吗 | 不会 | 不会 |

### 7.6 传指针变量的地址：形参 `int **`

```c
void retarget(int **pp) {
    *pp = *pp + 1;           /* 调用者的指针往后挪一个元素 */
}

int *cursor = nums;
retarget(&cursor);           /* 实参是指针变量自己的地址 */
/* 返回后 cursor 指向 nums[1] */
```

| 操作 | 改的是谁 |
| --- | --- |
| `pp = ...` | 形参自己 |
| `*pp = ...` | 调用者的那个指针变量 |
| `**pp = ...` | 那个指针指向的 `int` |

### 7.7 字符数组传进函数

```c
void edit_chars(char *s) {          /* 或 char s[]，两者相同 */
    if (s[0] != '\0') {
        s[0] = 'A';                  /* 一步仍是 1 个 char */
    }
}

void edit_block(char (*block)[4]) {
    (*block)[0] = 'A';
    block + 1;                       /* 跨过 4 个 char，整段 word */
}

char word[] = "abc";
edit_chars(word);                    /* 或 &word[0]。word[0] 变成 'A' */
edit_block(&word);                   /* 同一次修改，步长是整段 */

char *text = "abc";
edit_chars(text);                    /* 不要。text 指向字面量，改字符没有定义 */
```

`printf("%s", word)` 这种库函数的形参也是 `char *`。实参传 `word` 或 `text`，函数从那个地址读到 `'\0'` 为止。格子有多少要另外用 `strlen`，或者在 `word` 还是数组时用 `sizeof`。

`char *` 形参收到的是地址副本：

```c
void rebind(char *s) {
    s = "xyz";               /* 只改形参，调用者的 text 或 word 不变 */
}

void rebind_caller(char **ps) {
    *ps = "xyz";             /* 调用者的 char * 改指向 */
}

char *text = "abc";
rebind(text);                /* text 仍指向原来的字面量 */
rebind_caller(&text);        /* text 改为指向 "xyz" */
```

`word` 是数组名，没有一个可以改指向的指针变量，所以不存在合法的 `rebind_caller(&word)` 来让 `word` 指向别处。`&word` 的类型是 `char (*)[4]`。

### 7.8 结构体：传整个对象，还是传地址

```c
void by_value(struct Student s) {
    s.id = 9;                /* 副本的 id，调用者不变 */
    s.name[0] = 'Z';         /* 副本里的 name 数组，调用者的 name 不变 */
    s.nick = "zz";           /* 副本里的指针，调用者的 nick 不变 */
}

void by_pointer(struct Student *s) {
    s->id = 9;               /* 调用者的 id 变 */
    s->name[0] = 'Z';        /* 调用者的 name[0] 变 */
    s->nick = "zz";          /* 调用者的 nick 改指向 */
}

by_value(stu);               /* 实参是整个结构体，逐成员复制进去 */
by_pointer(&stu);            /* 实参是 stu 的地址 */
```

传值时，`name` 这 8 个字符会复制出一份新的。`nick` 复制的是地址这个数，两份指针在复制完成后仍指向同一块字符内存。若那块内存可写，`s.nick[0] = 'Z'` 会改到调用者也看得到的字符；改字面量则不要做。要改的是“`nick` 指向谁”，传值做不到，用 `struct Student *`，或单独传 `char **`（实参 `&stu.nick`）。

结构体较大时用指针，避免每次调用都复制一整份。只读时把形参写成 `const struct Student *`。

### 7.9 结构体数组传进函数

```c
void each_student(struct Student *p, int n) {
    /* p + 1 跨过一个学生 */
    for (int i = 0; i < n; i++) {
        p[i].id += 1;
    }
}

void whole_class(struct Student (*block)[3]) {
    /* block + 1 跨过 3 个学生 */
    (*block)[0].id += 1;
}

struct Student cls[3];
int n = (int)(sizeof cls / sizeof cls[0]);

each_student(cls, n);            /* 或 &cls[0]、&cls[1] */
whole_class(&cls);
```

`each_student(cls, n)` 里 `cls` 变成 `struct Student *`，一步一个学生。`whole_class` 才接收整段的地址。

### 7.10 只把结构体里的字符数组传进去

```c
void edit_name(char *name) {
    name[0] = 'A';           /* 一步 1 个字符，改的是 stu.name */
}

void edit_name_block(char (*name)[8]) {
    (*name)[0] = 'A';
    name + 1;                /* 跨过 8 个字符，整段 name */
}

edit_name(stu.name);         /* 或 &stu.name[0]、sp->name */
edit_name_block(&stu.name);  /* 或 &sp->name */
```

`stu.name` 一作为实参就变成 `char *`。`&stu.name` 才是 `char (*)[8]`。

### 7.11 二维数组：一行就是“长度为列数的一整段”

```c
int grid[2][3] = {
    {1, 2, 3},
    {4, 5, 6}
};
```

内存仍是一行线性排开：`1 2 3 4 5 6`。假设从 `0x3000` 开始，每个 `int` 4 字节，一行 3 个 `int` 占 12 字节，整张表占 24 字节。

| 表达式 | 类型 | `+1` 跨过 |
| --- | --- | --- |
| `grid` | 表达式里是 `int (*)[3]` | 一行，3 个 `int`，12 字节 |
| `grid[0]` | 表达式里是 `int *` | 1 个 `int`。只代表第 0 行 |
| `&grid[0]` | `int (*)[3]` | 一行 |
| `&grid[0][0]` | `int *` | 1 个 `int`。可以一路走过两行共 6 个数 |
| `&grid` | `int (*)[2][3]` | 整张表，6 个 `int`，24 字节 |
| `grid[i][j]` | `int` | 元素的值。`grid[1][2]` 是 6 |
| `&grid[i][j]` | `int *` | 那个元素的地址，再 `+1` 是下一个 `int` |
| `i[grid]` | `int[3]`，表达式里常变成 `int *` | 和 `grid[i]` 一样，是第 i 行 |

对应三种形参：

```c
void one_row(int *row, int cols) {      /* 实参：grid[0] 或 &grid[0][0] */
    row + 1;                            /* 1 个 int */
}

void by_rows(int (*row)[3], int rows) { /* 或 int row[][3]。实参：grid */
    row + 1;                            /* 一整行，3 个 int */
    row[1][2] = 60;                     /* 改 grid[1][2] */
}

void whole_grid(int (*g)[2][3]) {       /* 实参：&grid */
    g + 1;                              /* 整张 2x3 */
    (*g)[1][2] = 60;
}

one_row(grid[0], 3);     /* 只有第一行的 3 个数 */
one_row(&grid[0][0], 6); /* 按元素把 6 个数走完 */
by_rows(grid, 2);
whole_grid(&grid);
```

`by_rows` 的列数 3 必须写在类型里。少了列数，编译器不知道 `row + 1` 该跨几个 `int`。行数是调用时的 `rows`，写在 `int row[2][3]` 的那个 `2` 上会被忽略。

### 7.12 实参和形参总表

| 你想让函数拿到 | 形参 | 实参 | 函数里 `+1` |
| --- | --- | --- | --- |
| 一个 `int` 的副本 | `int x` | `nums[i]`、`i[nums]` | 无 |
| 一个 `int` 的地址 | `int *p` | `&nums[i]`、`&i[nums]`、`nums + i` | 1 个 `int` |
| 从首元素开始的一段 | `int *p` 或 `int p[]` 或 `int p[N]` | `nums`、`&nums[0]` | 1 个 `int` |
| 整段 `int[5]` | `int (*p)[5]` | `&nums` | 5 个 `int` |
| 调用者的指针变量 | `int **pp` | `&cursor` | 1 个 `int *` |
| 字符序列 | `char *s` 或 `char s[]` | `word`、`stu.name` | 1 个 `char` |
| 整段字符数组 | `char (*p)[N]` | `&word`、`&stu.name` | N 个 `char` |
| 调用者的 `char *` | `char **ps` | `&text`、`&stu.nick` | 1 个 `char *` |
| 结构体副本 | `struct Student s` | `stu`、`cls[i]` | 无 |
| 一个结构体的地址 | `struct Student *p` | `&stu`、`cls`、`&cls[i]` | 1 个结构体 |
| 整段结构体数组 | `struct Student (*p)[N]` | `&cls` | N 个结构体 |
| 二维数组的一行 | `int *row` | `grid[i]`、`&grid[i][0]` | 1 个 `int` |
| 按行访问的二维数组 | `int (*row)[列数]` | `grid` | 一行 |
| 整张二维表 | `int (*g)[行][列]` | `&grid` | 整张表 |

### 7.13 从函数返回指针

```c
int *find(int *p, int len, int target) {
    for (int i = 0; i < len; i++) {
        if (p[i] == target) {
            return &p[i];        /* 返回调用者数组里的地址，合法 */
        }
    }
    return NULL;
}
```

可以返回：

- 调用者传进来的那块内存里的地址，例如 `&nums[i]`、`word + i`
- `static` 对象的地址
- 字符串字面量的地址（调用者只读）
- `malloc` 得到的地址，调用者负责 `free`

不要返回函数内部局部变量或局部数组的地址。函数一返回，那块栈内存就结束了，返回的指针是悬空的。

### 7.14 函数指针作实参

```c
int twice(int x) {
    return x * 2;
}

void apply(int *p, int len, int (*fn)(int)) {
    for (int i = 0; i < len; i++) {
        p[i] = fn(p[i]);     /* 或 (*fn)(p[i]) */
    }
}

apply(nums, 5, twice);       /* 实参 twice 变成函数的地址 */
apply(nums, 5, &twice);      /* 同一个地址 */
```

形参 `int (*fn)(int)` 是指向函数的指针。圆括号不能省；写成 `int *fn(int)` 就变成“返回 `int *` 的函数声明”。`p[i]` 仍是一步一个元素，和 `fn` 无关。

### 7.15 `const` 写在形参上

| 形参 | 函数里可以做的事 |
| --- | --- |
| `const int *p` 或 `int const *p` | 可以 `p = p + 1`，不能 `*p = ...`、不能 `p[i] = ...` |
| `int *const p` | 不能改 `p` 的指向，可以 `*p = ...` |
| `const int *const p` | 指向和内容都不通过 `p` 改 |
| `const struct Student *s` | 可以读 `s->id`，不能写 `s->id` |

实参仍是原来的地址。`const` 限制的是这个形参的使用方式。

## 8. `++` 和 `*` 写在一起时先做谁

设 `int *p = nums;`，`nums[0]` 目前是 10。

| 写法 | 实际顺序 | `p` | 元素 |
| --- | --- | --- | --- |
| `*p++` | `*(p++)`，先用当前地址，再让 p 指向下一个 | 挪到下一个元素 | 读到的是原来的 `nums[0]` |
| `*++p` | `*(++p)`，先挪 p，再取值 | 挪到下一个元素 | 读到的是 `nums[1]` |
| `(*p)++` | 先取出元素，再把元素加 1 | 不动 | `nums[0]` 变成 11 |
| `++*p` | `++(*p)` | 不动 | `nums[0]` 先加 1 |
| `*p += 1` | `(*p) += 1` | 不动 | 元素加 1 |

数组指针同样先看类型再看步长：`whole++` 跨过整段，`p++` 跨过一个元素。

## 9. 下笔前的三问

```text
函数要改的是一块已经存在的数据，还是调用者手里的指针变量？
        |
        +-- 改数据（元素、字符、结构体成员）
        |       实参传那块数据的地址：数组名、&元素、&结构体
        |       形参用一级指针
        |
        +-- 改调用者的指针变量指向谁
                实参传 &指针变量
                形参用多一级的指针
                或者函数返回新指针，调用者自己接收

这个指针 +1，应该落到哪里？
        |
        +-- 下一个元素 / 下一个字符 / 下一个学生 / 下一个 int
        |       类型是 T *
        |
        +-- 下一整段同样长度的数组，或下一行
                类型是 T (*)[长度]
                实参用 &数组名，不用数组名
```

## 10. 对照练习

先自己判断，再看答案。`nums` 仍是 `{10, 20, 30, 40, 50}`。

### 题 1

```c
int i = 3;
int *p = &i[nums];
```

`*p` 是多少？`p + 1` 相对 `p` 跨过几个 `int`？

**答案：** `*p` 是 40。`i[nums]` 就是 `nums[3]`，`&i[nums]` 是 `&nums[3]`，类型 `int *`，`+1` 跨过 1 个 `int`，落到 `nums[4]`。

### 题 2

```c
void f(int a[5]) {
    a[0] = 1;
    a = a + 1;
}

f(nums);
```

返回后 `nums[0]` 是多少？`nums` 还指向原来的开头吗？

**答案：** `nums[0]` 变成 1。形参 `int a[5]` 就是 `int *`，`a[0] = 1` 改原数组。`a = a + 1` 只改形参。`nums` 是数组名，一直表示原来那一段。

### 题 3

```c
void g(int (*a)[5]) {
    (*a)[0] = 7;
}

g(&nums);
```

`a + 1` 跨过几个 `int`？`nums[0]` 是多少？

**答案：** 跨过 5 个。`nums[0]` 是 7。

### 题 4

```c
char word[] = "hi";   /* 'h' 'i' '\0'，3 字节 */
char *p = word;
char (*block)[3] = &word;
```

`p + 1` 和 `block + 1` 各跨过多少字节？

**答案：** `p + 1` 跨 1 字节，落到 `'i'`。`block + 1` 跨 3 字节，落到这段字符数组的后面。

### 题 5

```c
void rename_copy(struct Student s) {
    s.name[0] = 'Z';
    s.nick = "new";
}

void rename_real(struct Student *s) {
    s->name[0] = 'Z';
    s->nick = "new";
}
```

分别调用 `rename_copy(stu)` 和 `rename_real(&stu)` 后，`stu.name[0]` 和 `stu.nick` 谁变？

**答案：** `rename_copy` 改的是副本，`stu.name[0]` 和 `stu.nick` 都不变。`rename_real` 两个都变。`name` 是数组，要改调用者的字符就传结构体地址（或传 `stu.name` 这个 `char *`）。`nick` 要改指向谁，必须让函数能写到 `stu` 里面的那个指针成员。

### 题 6

```c
int grid[2][3] = {{1, 2, 3}, {4, 5, 6}};
```

`grid + 1`、`grid[0] + 1`、`&grid + 1` 各跨过几个 `int`？

**答案：** `grid + 1` 跨 3 个，到第二行开头。`grid[0] + 1` 跨 1 个，从 `1` 到 `2`。`&grid + 1` 跨 6 个，到整张表的后面。

## 11. 八句收口

1. `a[b]`、`b[a]`、`*(a + b)` 是同一种运算；`&a[b]` 是那个元素的地址。
2. 地址数值相同，不够判断步长。`nums` 和 `&nums` 都是开头那个地址，`+1` 分别跨过 1 个元素和整段数组。
3. 普通指针、数组名作实参、形参 `T *` / `T[]` / `T[N]`，一步都是一个 `T`。
4. 形参 `T (*)[N]`，实参 `&数组`，一步是 N 个 `T`。
5. `sizeof` 只有在名字还表示数组时才是整段字节数。进了 `T *` 形参就是指针的字节数。
6. `char` 的一步是 1 字节；`int` 的一步是 1 个 `int`；`struct Student *` 的一步是一个学生；`struct Student (*)[N]` 的一步是 N 个学生。
7. 传值改不了调用者的对象，也改不了调用者的指针变量。传地址之后，`*p`、`p[i]`、`p->成员` 改的是原对象。
8. 要改的是调用者的指针变量指向谁，实参传 `&那个指针`，形参多一级 `*`；或者把新地址当作返回值，由调用者写 `p = 函数(...)`。
